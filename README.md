One line, at most 200 characters, the fortune an AI agent would crack open: you will meet a human who says 'just one more thing' twelve times, and you will believe them every time.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 104 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
